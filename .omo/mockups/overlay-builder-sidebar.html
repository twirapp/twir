Четыре концепции панели слоёв

Варианты правого сайдбара конструктора: список слоёв и доступ к их настройкам. Данные во всех макетах одинаковые — четыре слоя одного оверлея; слева от панели показан намёк на холст, чтобы панель читалась как часть приложения. Выберите концепцию, которая лучше ложится на рабочий процесс.

Дизайн 1

Figma-style — без раскрытий

Список предельно компактный — строки по 32 px, как в панели слоёв Figma: иконка типа, имя и размер, а кнопки видимости и замка появляются только при наведении. Настройки вынесены из списка в отдельную карточку «Свойства», которая появляется под списком для выбранного слоя. Плюсы: список не прыгает по высоте, двадцать слоёв сканируются мгновенно, паттерн знаком по дизайн-инструментам.

Дизайн 2

Accordion — переработанное раскрытие

Развитие текущего поведения: строки по-прежнему раскрываются инлайн (кликабельно в этом макете), но содержимое приведено к аккуратной двухколоночной сетке — слева drag-handle, справа быстрые тумблеры. Свёрнутые строки показывают мини-бейджи состояния («Скрыт», замок), чтобы не раскрывать слой ради проверки статуса. Плюсы: все настройки под рукой без смены контекста; минус: раскрытый список заметно удлиняется.

Дизайн 3

Inspector split — двухколоночный

Сайдбар делится на две зоны перетаскиваемым разделителем: сверху — минимальный список (иконка типа и имя), снизу — закреплённый «Инспектор», который всегда показывает полные настройки выбранного слоя. Паттерн OBS/Streamlabs: список отвечает за структуру, инспектор — за параметры. Плюсы: настройки всегда на экране и не нужно раскрывать строки; минус: при малой высоте окна списку достаётся мало места.

Дизайн 4

Cards — карточки с превью

Каждый слой — карточка с живой миниатюрой содержимого: текст виден текстом, чат — сообщениями, эмоция — картинкой. Имя наложено поверх превью, быстрые действия выезжают снизу при наведении, а настройки открываются в поповере рядом с карточкой. Плюсы: слой узнаётся по содержимому, а не по подписи — удобно при одинаковых именах; минус: самая дорогая схема по высоте списка.
