## User-approved design decisions

1. **Ban gate**: per-platform — block only normalized Twitch events when `IsTwitchBanned`; Kick/VK flow normally.
2. **Reply semantics**: reply-with-fallback — `chat.write` always required; `chat.reply` adapters get the reply ID; VK (no `chat.reply`) falls back to a plain message (no error, no drop). Greeting shoutouts gated to Twitch only.
3. **VK channel_url**: runtime lookup — resolve via `/v1/current_user` with the binding owner's token at send time; no BotConfig persistence, no schema change.

## Excluded

- Finding #2 (VK webhook ingress) — user decision, VK stays on Centrifugo.
